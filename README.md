## Notebooks

| Notebook | What it covers | Highlight |
|---|---|---|
| `DL_Assignment_5_.ipynb` | **Activation functions** — Sigmoid, ReLU, Tanh implemented in NumPy and plotted | Side-by-side output table and curves |
| `dl_assgn_07-2.ipynb` | **Loss functions** — MSE and binary cross-entropy implemented from scratch | Shows why cross-entropy suits classification |
| `DL_assignment_8_.ipynb` | **Gradient descent from scratch** — fits `y = wx + b` by hand-coded updates | Loss curve and before/after parameter table |
| `dl_assgn_09-2.ipynb` | **SGD vs Adam** — same neural network on the Iris dataset, two optimizers | Adam: **96.7%** test accuracy vs SGD: **86.7%** |
| `GEN_AI_ASSIGNMENT_6.ipynb` | **Image style transfer** — CycleGAN vs VGG19 neural style transfer | Visual comparison on one landscape photo |
